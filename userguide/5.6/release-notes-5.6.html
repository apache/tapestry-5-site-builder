Tapestry 5.6

The tapestry-json improvements (TAP5-2640) introduced an incompatibility with dependencies built with earlier versions than Tapestry 5.6.2. The method JSONObject#get(String) will fail with a NoSuchMethodError exception due to a signature change to conform to the Map interface.

Possible workarounds:

  • Use a newer version of the dependency build with at least Tapestry 5.6.2

  • Shade the dependency and update it manually

  • Fork the dependency and update it manually

Tapestry 5.6.3

Improvements Made

  • TAP5-2665 - Disallow requests for folders in the classpath by default

Bugs Fixed

  • TAP5-2664 - PropertyShadowBuilder fails when interface inherits same method more than once

  • TAP5-2663 - ChecksumPath should ignore slashes at the end of URLs

Tapestry 5.6.2

Improvements Made

  • TAP5-2662 - Make BeanEditor/BeanEditForm/FormGroup more accessible

  • TAP5-2657 - Blacklist modules autoloaded via manifests

  • TAP5-2655 - Create annotation to disable validation in event handler methods

  • TAP5-2651 - TypeCoercer should favor exact match coercions over intermediate ones

  • TAP5-2649 - Configuration should have consistent ordering

  • TAP5-2640 - better exceptions in tapestry-json code, plus JSONArray now implementing Collection and JSONObject implementing Map

Bugs Fixed

  • TAP5-2661 - Allow options to be passed to GoogleClosureMinimizer

  • TAP5-2660 - Empty string and null namespaces should be treated as the same in Element

  • TAP5-2659 - Direct instantiation of ComponentResourceSelector should be replaced with delegation to ComponentRequestSelectorAnalyzer

  • TAP5-2658 - Tuple should implement hashCode based on its values

  • TAP5-2656 - Disabling strict CSS URL rewriting still throws exceptions for non-existing files

  • TAP5-2643 - Label component throws NPE when corresponding form field isn’t rendered

  • TAP5-2636 - Non-unique advice IDs silently override each other in random order on application startup

Tapestry 5.6.1

Bugs Fixed

  • TAP5-2642 - Tapestry 5.6.1 asset request fails due to missing dependency

Tapestry 5.6.0

The main new features are:

  • TAP5-2588 - Added support for Java 14 bytecode. Tapestry 5.6.0 now supports Java 8 through 14.

  • TAP5-2631 - Tapestry form are more accessible with automatic generation of WAI-ARIA attributes.

Improvements Made

  • TAP5-2631 - Make Tapestry forms more accessible with automatic generation WAI-ARIA attributes

  • TAP5-2626 - Update Closure Compiler to latest version available (v20200504)

  • TAP5-2625 - Upgrade Prototype.js to the latest one, 1.7.3

  • TAP5-2624 - Support Java 14 bytecode by upgrading embedded ASM version to 8.0.1

Bugs Fixed

  • TAP5-2635 - Deadlock when using eager-loaded services through PeriodicExecutor

  • TAP5-2633 - ChainBuilder fails with interface containing static methods

  • TAP5-2632 - ContextAssetRequestHandler doesn’t handle slashes in paths correctly

  • TAP5-2602 - 5.4 LinkSubmit does not work with Prototype JS
